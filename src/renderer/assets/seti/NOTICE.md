# Third-party notice — Seti file icons

`seti.woff` is vendored from [VS Code's built-in `theme-seti` extension][theme-seti], which
packages the icon font of the [Seti UI][seti-ui] project. Manifold's file tree renders these
glyphs through `src/renderer/components/editor/file-tree/seti-icons.ts`; the accompanying
glyph/colour tables in `seti-icon-data.ts` are generated from the same upstream theme by
`scripts/generate-seti-icons.mjs`.

[theme-seti]: https://github.com/microsoft/vscode/tree/main/extensions/theme-seti
[seti-ui]: https://github.com/jesseweed/seti-ui
